    ostk.simulation.component.Geometry¶

    class Geometry(
    self,
    name: ostk.core.type.String,
    composite: ostk.mathematics.geometry.d3.object.Composite,
    component: ostk.simulation.Component,
    )¶

    Bases: object

    Physical geometry attached to a component.

    Geometry represents the physical shape and structure of a component, enabling spatial operations like intersection and containment checks with other geometries or celestial objects.

    Create a Geometry instance.

    Parameters:

    • name (str) -- The geometry name.

    • composite (Composite) -- The 3D composite geometry object.

    • component (Component) -- The parent component. It must have a frame.

    Returns:

    The geometry instance.

    Return type:

    Geometry

    Raises:

    RuntimeError -- If the name is empty or the component has no frame.

    Example

    >>> geometry = Geometry(
...     name="solar-panel",
...     composite=panel_composite,
...     component=satellite
... )
