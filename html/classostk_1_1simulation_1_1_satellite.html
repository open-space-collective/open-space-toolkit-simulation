Detailed Description

A satellite in the simulation.

A Satellite is a specialized Component that has an associated flight Profile and a dedicated reference frame derived from that profile.

const Satellite& satellite = simulator.getSatelliteWithName("sat-1");
const Shared<const Profile>& profile = satellite.getProfile();
