Detailed Description

A component within the simulation hierarchy.

A Component extends Entity with a type, tags, geometries, child components, and a reference frame. Components form a tree structure where each component can hold sub-components and geometries.

const Component& sensor = satellite.getComponentWithName("camera");
std::optional<Component::Type> type = sensor.getType();
Array<String> tags = sensor.getTags();
