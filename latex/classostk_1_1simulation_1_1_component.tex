\doxysubsection{Detailed Description}
A component within the simulation hierarchy. 

A \mbox{\hyperlink{classostk_1_1simulation_1_1_component}{Component}} extends \mbox{\hyperlink{classostk_1_1simulation_1_1_entity}{Entity}} with a type, tags, geometries, child components, and a reference frame. Components form a tree structure where each component can hold sub-\/components and geometries.
